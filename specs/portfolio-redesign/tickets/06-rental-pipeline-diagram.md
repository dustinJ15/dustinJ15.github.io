**What to build:** A technical reader opening the rental-pipeline case study sees the shape of
the work. It is a pipeline rather than a UI, so there is nothing to screenshot; it gets a
hand-authored inline SVG showing sixteen parsers converging on one schema. Inline because it has
to pick up the site's tokens and read correctly on the near-black ground, and because a diagram
of a pipeline is structure, not a picture.

It is a diagram of the shape, not a disclosure. It shows that there are sixteen inputs and one
output; it does not name a client, a source system or anything specific to that work's data.
